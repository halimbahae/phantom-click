Phantom Click

Cross-platform auto-clicker — TUI • GUI • MCP • Library

Click at inhuman speeds — CLI, desktop GUI, MCP server for AI assistants, and a reusable Rust library.

Install ↓ Features ↓ Tools ↓ Usage ↓ Links ↓

Features

Blazing CPS

Click rates beyond 1,000 CPS with configurable interval. OS-level clicks via enigo.

Trusted Browser Clicks

CDP-based browser_click sends trusted events via Chrome DevTools Protocol WebSocket — passes event.isTrusted checks.

Global Hotkeys

Toggle with C, adjust speed with Z/S, help with H, quit with Q or Esc.

MCP Integration

MCP server for AI coding assistants — Claude, Cursor, Windsurf, and any stdio JSON-RPC 2.0 client.

Cross-platform

macOS, Linux, Windows. One codebase, native cursor control on each platform.

Matrix Rain TUI

Green-on-black terminal UI using crossterm. Plus a native desktop GUI with eframe/egui.

Install

Binaries curl -fsSL https://raw.githubusercontent.com/halimbahae/phantom-click/main/install.sh | bash
Downloads prebuilt binaries from the latest GitHub release.
cargo cargo install phantom-click-cli phantom-click-mcp phantom-click-gui
Library cargo add phantom-click
Then use clicker::click_for_duration() or cursor::move_to() in your Rust project.
Release gh release download --repo halimbahae/phantom-click

Tools

phantom-click-cli

crates.io — v0.2.0

Terminal UI auto-clicker with matrix-rain aesthetics. Set CPS, start/stop, adjust speed without leaving the terminal.

  • Global hotkeys
  • Real-time CPS display
  • Minimal & fast

phantom-click-gui

crates.io — v0.1.0

Native desktop GUI using eframe/egui. Point, click, configure visually.

  • Native macOS/Linux/Windows
  • Visual CPS slider
  • Start/Stop controls

phantom-click-mcp

crates.io — v0.4.0

MCP server for AI assistants. 6 tools: get_cursor_position, move_mouse, click, click_for_duration, get_status, browser_click.

  • Stdio JSON-RPC 2.0
  • Browser trusted clicks via CDP
  • Silent mode for daemon use

phantom-click

crates.io — v0.2.0

Rust library powering everything. clicker, cursor, and platform abstractions.

  • clicker::click_for_duration()
  • cursor::move_to(x, y)
  • cursor::position()

Quick Start

$ phantom-click              # Launch TUI (default 10 CPS)
$ phantom-click --cps 50     # Start at 50 clicks/sec
Press C to toggle, Z/S for speed, Q to quit
$ phantom-click-mcp          # Start MCP server
$ phantom-click-gui          # Launch desktop GUI
# AI assistant MCP config (claude.json / cursor.json):
{
  "mcpServers": {
    "phantom-click": {
      "command": "phantom-click-mcp"
    }
  }
}
